# 本版报告

研究问题：实测计数率与距离平方的乘积为什么偏离常数？一个包含实际装置的模型能解释到什么程度？

图 1 只显示原始数据；虚线是通过 30 cm 点的水平参照，不是拟合。图 2 使用同一假设距离计算修正后的数据和 Geant4 预测；三个远点用于定标，五个近点用于比较。下图比值为 1 表示数据与模型一致。定标后的近点检验是事后模型检查；模型参数在看数据后调整过，且误差条不含未测量的共同系统误差。

main.tex 与 Imperial_lab_report.cls、images/ 为 LaTeX 所需文件。连续运行两次 pdflatex main.tex 可编译。plot_report.py 依赖 numpy、pandas、matplotlib，从 data/ 中的分析结果重绘两图。data/ 保留数据、模拟摘要和协方差。原始分析合并了 141 次观测。本版使用已有模拟，未重新运行 Geant4。论文需自行核对装置参数和引用，不能保证具体分数。
